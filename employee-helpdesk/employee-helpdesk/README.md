# Employee Helpdesk & Asset Management System

## Overview

A medium-level Java Spring Boot backend project designed for learning and practicing enterprise backend development.

This is a separate training project and is not part of the One Enterprise Cloud Platform.

## Technology

- Java 17+
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Spring Security
- JWT
- REST APIs
- Swagger/OpenAPI
- JUnit 5
- Mockito
- Maven
- Git

## Setup

1. Clone the repository.
2. Create PostgreSQL database:

   employee_helpdesk_db

3. Update PostgreSQL username and password in application.properties.
4. Run the Spring Boot application.
5. Open Swagger:

   http://localhost:8080/swagger-ui.html

## Modules

- Authentication
- Employee Management
- Asset Management
- Asset Assignment
- Ticket Management
- Ticket Assignment & Workflow

## Development

Each developer must create a feature branch before implementing their assigned module.
